Booker lab

The PiperX full-screen meeting booker (LightboxExperience → MeetingTimeSelector), with no routing, rep, or calendar. The markup is captured from fireball by rendering the real components, and the styles are the app's own Panda CSS, so what you see here is what a visitor sees. Each frame is its own viewport, so the app's mobile media queries (≤ 767px) apply. Open one frame on its own to use DevTools on it.

What to check

  • The bug (QAI-6749), from code without the fix (320 to 414): four time columns, and "9:00 AM" wraps to two lines and spills past the 36px pill. The day strip has arrows on both sides, squeezing the seven day cards.
  • Fixed (three columns, one-line pills): below 768px, three columns, the arrows beside the month title, and every label on one line at 320, 375 and 414. At 768 and wider, nothing changes.
  • The preview and the patch try each half of the fix on code that doesn't have it yet. The layout alone still wraps "10:00 AM" at 320. The CSS alone stops the wrapping, but with four columns the last one runs past the card. You need both.
  • Focus: Tab into a frame. Day cards and time pills should lift on :focus-visible. Clicking a time selects it (aria-pressed).

Refresh the capture after fireball changes: npm run booker:refresh. See the README.
