Cards

The cards Piper puts in the chat timeline when it shares an offer (SharedOfferRenderer: the offer’s image, headline and short URL) or a page (ShareContentRenderer: a preview image and the page title). Both are LinkPreviewCard underneath. It's markup only, with no Piper running. Each state is a different conversation, captured from fireball by rendering the whole messenger (Main) in text mode, in an open shadow root on #qualified-multimodal-host with production’s host style. The headline is the theme’s primary colour, so the Theme options matter here. Hover a card to see its lift. Each frame is its own viewport. Open one on its own to use DevTools on it.

What to check

  • Offer cards: the image sits on the left at 160px, with the headline in the theme’s primary colour and the short URL under it. With no image, the card is text only.
  • Long headlines and URLs wrap inside the card, and the image stretches to the card’s height.
  • Shared content titles should be one line. The long title is meant to be cut to one line with an ellipsis (lineClamp: 1), but it shows in full: the messenger’s Panda config ejects the preset that turns lineClamp into -webkit-line-clamp, so production’s CSS has a bare line-clamp: 1 that browsers ignore.
  • Hover and focus: hovering lifts a card with a shadow; Tab to one for the primary-colour focus outline.

Refresh the capture after fireball changes: npm run cards:refresh. See the README.
