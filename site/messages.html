Messages

The PiperX chat timeline: the agent’s and visitor’s messages, rich text, the line shown when a sales rep joins, and the thinking indicator. It's markup only, with no Piper running. Each state is a different conversation, captured from fireball by rendering the whole messenger (Main) in text mode, so the timeline keeps its real spacing, header and composer. It sits in an open shadow root on #qualified-multimodal-host with production’s host style, and the Theme options set the same --q-* properties on the host that applyThemeCssVars does. Agent text is HTML, as the server sends it. Each frame is its own viewport. Open one on its own to use DevTools on it.

What to check

  • Visitor and agent read apart: the visitor’s messages are grey bubbles on the right; the agent’s are plain text on the left.
  • Rich text: bold, bulleted and numbered lists keep their spacing, links are underlined, and only the link that leaves the site has the external-link glyph.
  • Tables fit: the plan table has borders and stays inside the panel at 320.
  • Long text wraps: the long visitor message, the bare URL and the word with no spaces all wrap instead of overflowing.
  • A rep joins: the header switches to the rep, and the joined line is centred with the rep’s avatar. With reps offline, the composer gives way to the offline notice. The line’s “Today” is from the capture day.
  • Thinking: only the dot for the first second, then the “Thinking…” label.
  • Mobile: the layout comes from the app’s isMobile signal at capture time, not the frame width.

Refresh the capture after fireball changes: npm run messages:refresh. See the README.
