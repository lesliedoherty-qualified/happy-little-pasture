Multimodal

The PiperX messenger (Main) in text mode, as markup only: no Piper, and nothing behind the buttons. The markup is captured from fireball by rendering the real component. It sits in an open shadow root on #qualified-multimodal-host with production’s host style, so :host rules, inherited custom properties and ::part() behave as on a customer’s page. Use it to check the QAI-6788 header hooks: the values below are set on the host with style.setProperty. Each frame is its own viewport. Open one on its own to use DevTools on it.

What to check

  • Unset looks like master: with every hook blank, the header has no band: a dark name and icons, a muted job title and the grey hover fill.
  • The band reaches the edges: with Classic header, the blue band runs to the card’s top and side edges, with no strip of card above or beside it.
  • Focus stays visible: Tab into a frame to the close button. Its focus fill (--q-toolbar-button-hover-background) is its only focus indicator, so it must still show on the band.
  • The name is a heading: when the agent has a name, it’s an <h2> (“Bob Llama” here). Open a frame and inspect it.

Refresh the capture after fireball changes: npm run multimodal:refresh. See the README.
